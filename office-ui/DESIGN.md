# AURUM: офис агентов. UI/UX-спецификация

Рабочий прототип: `office-ui/index.html` (один файл, без зависимостей, кроме Google Fonts).
Откройте его в браузере, чтобы увидеть все состояния. Данные в прототипе демонстрационные.

## 1. Идея

Офис агентов как ночная диспетчерская: чёрный графит, тёплое золото, плёночное зерно.
Агенты — минималистичные фигуры-манекены с золотым кантом и «визором». Пиксель-арт не используется.
Состояние агента считывается сразу по трём признакам: цвет кольца под фигурой, свечение монитора и пузырь над головой.

### Статусы агента
| Статус | Цвет | Признак на сцене |
|---|---|---|
| Работает | `#C9A45C` золото | монитор светится, строки кода бегут |
| Думает | `#9DB1C4` сталь | пузырь «···», холодное свечение |
| Ждёт ответа | `#E08A4F` янтарь | пузырь «!», быстрая пульсация кольца |
| Перерыв | `#6F6B62` | агент идёт в лаунж |
| На встрече | `#D8CFBB` кость | агент в переговорной, на стене включается экран |
| На паузе | `#4A4740` | пунктирное кольцо, монитор гаснет |
| Без задачи | `#A39C8C` | пунктирное кольцо, роль ещё не назначена |

Цвета статусов — семантические, в качестве акцента их не использовать.

### Шрифты (все с кириллицей)
| Роль | Шрифт | Где |
|---|---|---|
| Дисплей | Unbounded 600, капс, трекинг .24–.34em | логотип, eyebrow-лейблы, надписи на полу |
| Акцент | Cormorant Garamond Italic 600 | имя агента в досье, название зала |
| Интерфейс | Manrope 400–700 | весь остальной текст |
| Данные | JetBrains Mono 400–500, tabular-nums | цифры, файлы, время, статусы |

### Фактура
- Зерно: SVG `feTurbulence` на фиксированном слое поверх всего, `opacity .085`, дрожит `steps(6)`.
- На канвасе дополнительно рисуется шумовой паттерн `alpha .05`.
- Виньетка поверх сцены: радиальный градиент к `rgba(0,0,0,.55)`.
- Скругления 2–3px. Тени не используются, глубину дают линии и свечение.

## 4. Этаж (18 × 12 клеток, изометрия 2:1, клетка 64×32)

| Зона | Клетки | Наполнение |
|---|---|---|
| Кабинет оркестратора | x 0–5, y 0–5 | стол оркестратора, пол из тёмного ореха, стеклянные стены с дверью |
| Open space | x 5–14, y 0–8 | 6 столов в два ряда (один свободен), проходы x 5.6 / 8.35 / 11.05 |
| Серверная | x 14–18, y 0–8 | 5 стоек с мигающими диодами, стол ДевОпса, фальшпол с золотой сеткой |
| Коридор | y 8–9 | золотые полосы-инкрустации, общий маршрут для всех агентов |
| Переговорная | x 0–6, y 9–12 | стол на 5 мест, экран на стене |
| Лаунж | x 6–12, y 9–12 | диван, кофемашина с паром, ковёр с двойной золотой рамкой |
| Архив | x 12–18, y 9–12 | стеллажи с корешками, стол Документалиста |

На левой стене надпись AURUM. Окна на задних стенах с огнями города.

Порядок отрисовки: плита этажа → пол → надписи на полу → стены → мебель и агенты, отсортированные по `x + y` центра → затемнение «ночь» → свечение (`lighter`) → бейджи → зерно.

### Агент
- Тень-эллипс, кольцо статуса 14×7 (пульсирует), кольцо выделения 19×9.5 золотом.
- Корпус: скруглённый прямоугольник с градиентом графита, золотой кант справа, код агента на спине.
- Голова цвета кости с золотым «визором».
- Сидит за столом или в переговорной, стоит и идёт в остальных случаях (шаг и покачивание).
- Над фигурой бейдж: точка статуса и код. Полное имя показывается при зуме > 0.8, при наведении и при выделении. Над выбранным агентом висит золотой ромб.

### Движение
Маршрут: место → свои точки выхода → коридор (y 8.5) → точки входа цели → цель. Скорость 2 клетки/с.

## 5. Состав команды (текущий)

| Код | Агент | Роль | Место |
|---|---|---|---|
| DM | Директ-менеджер | готовит и отправляет рассылки: сегменты базы, темы писем, A/B-тесты, цепочки | кабинет |
| A2 | Агент 02 | роль не назначена | open space, ряд 1 |
| A3 | Агент 03 | роль не назначена | open space, ряд 1 |
| A4 | Агент 04 | роль не назначена | open space, ряд 1 |

Агент без роли получает статус «Без задачи» (`free`, `#A39C8C`, пунктирное кольцо, монитор не горит).
Он сидит на месте и иногда уходит в лаунж. Когда роль появится, уберите флаг `unassigned` и заполните `role`, `tasks`, `events`.
Перед отправкой рассылки Директ-менеджер ждёт подтверждения: в досье появляется блок «Вопрос агента» и активная кнопка «Подтвердить».
Свободные столы (3 в open space, в серверной и в архиве) оставлены под новых агентов.

## 6. Взаимодействие
| Действие | Результат |
|---|---|
| Клик по агенту на сцене или в списке | выбор: досье, кольцо и ромб на сцене |
| Перетаскивание | панорама |
| Колесо, кнопки + / − | зум 0.35–3 к курсору или к центру |
| Кнопка ◇ | весь этаж в кадре |
| «Следить камерой» | камера плавно ведёт выбранного агента |
| «Подтвердить» | активна только у статуса «Ждёт ответа», агент возвращается к работе |
| «Пауза / Продолжить» | агент замирает, монитор гаснет |
| Вечер / Ночь | ночью сцена темнее, свечение мониторов в 1.7 раза сильнее |
| Фильтры списка | все / работают (включая «думает» и «на встрече») / ждут / без задачи |
| Поле «Новая задача» + «Поручить» | свободный агент сразу берёт задачу и идёт за стол; занятый ставит её в очередь |
| Очередь «В очереди» | список поручений по порядку, × убирает задачу |
| Приёмка | когда поручение готово, агент переходит в «Ждёт ответа» с вопросом «Результат готов… Принять?»; «Подтвердить» закрывает задачу, агент берёт следующую из очереди или становится свободным |
| «Роль и инструкции» | у агента без роли блок открыт, поле задачи заблокировано до назначения; после назначения меняются имя, код на аватаре и бейдж на сцене |

## 7. Подключение к реальным агентам (для Codex)

В прототипе симуляция живёт в `tick()`. Её нужно заменить на поток событий, например:

```ts
type AgentStatus = 'work' | 'think' | 'wait' | 'idle' | 'meet' | 'pause' | 'free';
interface AgentEvent {
  agentId: string;
  status?: AgentStatus;
  task?: { title: string; file: string; question?: string };
  progress?: number;          // 0–100
  tokens?: { in: number; out: number };
  log?: string;
}
```
- `status: 'wait'` + `task.question` → пузырь «!» и активная кнопка «Подтвердить». Её клик должен отправлять ответ агенту.
- Формы в досье сейчас меняют только локальное состояние. Для реальной работы:
  - отправка `#f-task` → `POST /agents/:id/tasks { title }`;
  - отправка `#f-role` → `PUT /agents/:id/role { name, instructions }` (инструкции становятся системным промптом агента);
  - «Подтвердить» → `POST /agents/:id/answer { approved: true }`;
  - × в очереди → `DELETE /agents/:id/tasks/:taskId`.
- `status: 'idle'` / `'meet'` → вызвать `routeTo()` к свободному месту в лаунже или переговорной.
- Токены за интервал кладите в `agent.spark` (последние 32 значения), график строится сам.

Рекомендуемое разбиение на компоненты: `TopBar`, `RosterPanel` (`StatGrid`, `FilterChips`, `AgentRow`), `FloorCanvas` (рендер и камера отдельно от данных), `DossierPanel` (`TaskBlock`, `Sparkline`, `Actions`), `ActivityLog`, `StatusRail`.
